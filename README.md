# AliBulkFinder — поиск выгодных оптовых предложений на AliExpress.ru

AliBulkFinder — программа для Windows, которая помогает сравнивать предложения на **aliexpress.ru**, когда нужно купить много одинаковых товаров, например 200 рулеток-ретракторов для бейджей. Она ищет карточки товаров, пытается определить количество штук в упаковке, рассчитывает число упаковок для заказа и, если источник данных позволяет, оценивает **полную цену всех товаров с доставкой** в выбранный город России.

**Программа не покупает товары, не авторизуется в аккаунте и не оформляет заказы.** Окончательную цену, комплектацию и доступность нужно проверять на сайте перед покупкой. Поиск использует неофициальную библиотеку [aliexpress-ru-mcp](https://github.com/SZhukovWork/aliexpress-ru-mcp); если AliExpress изменит свой сайт или временно ограничит обращения, отдельные данные могут оказаться недоступны.

## 1. Первый запуск

1. Установите **Python 3.10 или новее** для Windows (с компонентом Tkinter). При установке желательно включить добавление Python в `PATH`.
2. Распакуйте архив программы в отдельную папку.
3. Один раз запустите **`setup_windows.bat`**. Нужен интернет для установки библиотек и Chromium; обычно достаточно дождаться сообщения `Setup complete!`.
4. Для обычной работы запускайте **`start.bat`**. Программа откроется развёрнутым окном, с обычной панелью задач Windows.
5. Если понадобится подробно исследовать проблему с подключением или поиском, вместо обычного запуска используйте **`start_diagnostic.bat`**.

Если вы уже пользовались программой, при обновлении сохраните папки `.venv` и `cache`, а также файл `settings.json` (если он есть). Пользовательские настройки **не сбрасываются** при обновлении. Значения по умолчанию ниже относятся к первому запуску без файла `settings.json`.

## 2. Быстрый пример поиска

Для поиска 200 ретракторов с доставкой в Санкт-Петербург:

1. В поле **«Поисковые запросы»** впишите несколько вариантов названия, каждый с новой строки: `рулетка ретрактор для бейджа`, `ретрактор для бейджа 100 шт`, `badge reel retractable holder`.
2. Оставьте город **Санкт-Петербург** и **«Нужно штук» — 200**.
3. В поле **«Обязательные слова/фразы»** укажите через запятую, например: `рулетк, ретрактор, retractable, badge reel, катушк`.
4. Нажмите **«Найти и рассчитать»**. Предложения будут появляться в таблице по мере обработки.
5. Отсортированные варианты покажут стоимость товаров, доставку и предполагаемую общую цену; если доставку определить не получилось, общая цена останется неизвестной.
6. Выделите интересующую строку и нажмите **«Открыть товар»**, чтобы проверить цену и комплектацию на AliExpress. Выдачу можно сохранить кнопками **«Экспорт CSV»** (для Excel) или **«JSON»**.

Во всех редактируемых полях доступны обычные сочетания **Ctrl+A** (выделить всё), **Ctrl+C** (копировать), **Ctrl+V** (вставить) и **Ctrl+X** (вырезать), в том числе на русской раскладке клавиатуры.

## 3. Параметры поиска

| Поле | Что означает |
|---|---|
| **Поисковые запросы** | Каждый запрос — с новой строки. Программа ищет по ним последовательно и объединяет найденные уникальные карточки. |
| **Город доставки** | Город в России, для которого запрашивается оценка доставки. Адрес и пункт выдачи в расчёте не используются. |
| **Нужно штук** | Сколько **физических единиц товара** требуется, а не сколько упаковок. По умолчанию 200. |
| **Макс. лишних штук** | Разрешённое превышение количества, если товар продаётся упаковками. `0` — строго необходимое количество. |
| **Страниц на запрос** | Максимум страниц поисковой выдачи для каждого запроса (1–5). Чем больше, тем дольше работа. |
| **Изучить карточек** | Максимум уникальных карточек для подробного исследования (1–5000). Реально их может быть меньше, чем задано. |
| **SKU на карточку** | Сколько вариантов одного товара проверять дополнительно (1–4). SKU — конкретный вариант комплектации, цвета или упаковки. |

**Почему предупреждение о 99 лотах?** Используемая неофициальная библиотека позволяет запросить цену и доставку максимум для **99 лотов одного SKU** одновременно. Один лот может содержать 1, 20, 50 или 100 физических штук. Поэтому 200 отдельных товаров по одному в лоте могут не получить полной оценки доставки, а две упаковки по 100 штук могут получить. Это не ограничение на значение «Нужно штук» и не запрет покупать более 99 единиц на сайте.

## 4. Фильтры названия и полной цены

**Обязательные слова/фразы (ИЛИ).** Введите несколько слов или фраз через запятую. Достаточно **одного** совпадения в названии товара. Можно вводить **часть слова**: `принт` найдёт «принтер» и «термопринтер», `рулетк` — «рулетка» и «рулетки». Поиск не зависит от регистра. Текст сравнивается как последовательность символов, без интеллектуального распознавания синонимов.

**Нежелательные слова/фразы.** Помогают исключить товары, например `lanyard, шнурок, ремешок`. Если в названии одновременно найдены обязательное и нежелательное слова, вариант сохраняется с предупреждением как сомнительный: иногда нужный ретрактор продаётся вместе со шнурком.

**Режимы фильтра названий:**

- **Строгий:** карточки без обязательных слов не проходят в дальнейшую проверку.
- **Мягкий:** спорные карточки, где обязательные слова не нашлись, могут остаться с отметкой «сомнительно».
- **Без фильтра:** названия не фильтруются.

**Минимум / максимум за весь заказ, ₽** — необязательный диапазон **итоговой суммы за необходимое количество с доставкой**, а не цены одной штуки или одного лота. Пустое поле означает отсутствие соответствующей границы. Если итоговая доставка неизвестна, программа не считает её равной нулю.

**Показывать без известной итоговой цены** — включите, чтобы видеть и предложения, для которых пока нельзя рассчитать итог. Такой вариант потребует ручной проверки на сайте. Ценовой фильтр применяется к отображению и экспорту уже обработанных предложений, а не избавляет от всех запросов к сайту заранее.

## 5. Защита от ограничений AliExpress

Эти настройки находятся в отдельной строке под фильтрами. Программа старается делать паузы, а не прекращать длительный поиск при ограничениях со стороны сайта.

| Настройка | Начальное значение | Значение |
|---|---:|---|
| **Интервал, сек.** | **3** | Минимальный интервал между новыми вызовами поиска/проверки. Не пропускается кнопкой. Допустимо 1–3600 сек. |
| **Вызовов до паузы** | **18** | Размер серии обращений, после которой может выполняться **плановая** пауза. Значение `0` отключает её. |
| **Пауза по лимиту, мин.** | **0** | Продолжительность плановой паузы после серии. Значение `0` отключает её даже при ненулевом числе вызовов. |
| **Лимит сайта, мин.** | **15** | Если AliExpress ограничивает запросы, программа ждёт указанное время и повторяет попытку. |
| **После сбоя сети, мин.** | **2** | Пауза перед повтором при некоторых ошибках поиска и соединения. |

**Важно:** `0` **хотя бы в одном** из двух полей — **«Вызовов до паузы»** или **«Пауза по лимиту»** — полностью отключает *плановые* паузы. Обычный интервал между обращениями и пауза при ограничении запросов сайтом продолжают работать. Значение `0` для двух последних пауз запрещено, чтобы программа не повторяла ошибочные запросы немедленно.

Если в нижнем журнале появляется **«AliExpress ограничил запросы»**, сайт (или промежуточный сервер библиотеки) сообщил о временном ограничении. Программа ждёт и пытается снова, пока поиск не завершён либо не нажата остановка. Продолжительность блокировки определяет AliExpress; даже после ожидания ограничение может оставаться активным. Автоматические паузы уменьшают частоту обращений, но не гарантируют отсутствие ограничений.

Кнопка **«Пропустить паузу»** доступна только во время планового ожидания, ограничения сайтом или паузы после ошибки. Она **не отменяет** минимальный интервал между запросами и не снимает ограничение на стороне AliExpress. Частый ручной пропуск ожиданий может ухудшать ситуацию.

## 6. Таблица предложений, статусы и кнопки

В таблице показаны название, размеры упаковок, необходимое число лотов, цена лота, стоимость товаров, доставка, итог и цена за физическую штуку. Строки ранжируются по степени достоверности данных и общей стоимости.

| Статус | Что означает |
|---|---|
| **ОЦЕНКА ПО ГОРОДУ** | Получена оценка цены товаров и доставки для заданного города. **Это ещё не финальная цена корзины.** |
| **ДОСТАВКА НЕИЗВЕСТНА** | Стоимость товаров может быть известна, но достоверной цены доставки нет, поэтому итог не указан. |
| **НУЖНА ПРОВЕРКА** | Недостаточно данных о комплектации, упаковке или числе лотов; нужно открыть карточку и проверить самостоятельно. |

Пометка **«сомнительно»** относится к фильтру *названия*, а не непосредственно к цене или надёжности продавца.

**«Проверить SKU»** заново запрашивает оценку выделенного варианта товара, если позволяет ограничение на 99 лотов. **«Открыть товар»** открывает ссылку в браузере. **«Очистить кэш»** удаляет сохранённые ответы поиска и карточек, но не отменяет текущую защитную паузу.

**«Остановить поиск»** прерывает длительный поиск, в том числе во время ожидания, и оставляет уже найденные предложения в таблице для экспорта. Обычное завершение поиска также оставляет результаты доступными до закрытия приложения. Уже полученные ответы частично сохраняются в кэше, но после закрытия программы точная позиция незавершённого поиска не восстанавливается.

**Ожидаемое время завершения** — приблизительная оценка, а не обещание: она зависит от числа найденных карточек, кэша и повторных ограничений. Прогресс и текущая операция отображаются под таблицей и в нижнем журнале. Разделитель между таблицей и журналом можно двигать мышкой вверх или вниз; у журнала есть полоса прокрутки.

## 7. Сохранение результатов и время

**«Экспорт CSV»** создаёт файл для Excel (разделитель `;`, кодировка UTF-8 с BOM). **«JSON»** — файл для другой обработки. Экспортируются предложения, которые **видны с текущими ценовыми фильтрами**.

Все даты, которые формирует программа и отображает для товаров, приводятся к виду **`31.10.2026 21:12:21`** в **локальном часовом поясе Windows**, включая полученные от сервера времена с указанием UTC. Серверные технические сообщения в сыром виде могут содержать свои даты.

## 8. Журналы, диагностика и ошибки

В нижнем окне отображаются последние действия. Для расширенной информации в папке программы используются файлы:

- **`alibulkfinder_debug.log`** — обращения к промежуточному сервису, ошибки и технические подробности. Создаётся при работе приложения, когда возникают события для записи.
- **`alibulkfinder_console.log`** — дополнительный вывод консоли и внешнего сервера. Записывается при запуске **`start_diagnostic.bat`**.

Оба журнала автоматически **ротируются**: текущий файл не больше примерно 5 МиБ, плюс три резервные копии (`.log.1`, `.log.2`, `.log.3`). Оба журнала вместе занимают около 40 МиБ максимум. Перед передачей журналов другому человеку проверьте их содержимое: там могут быть поисковые запросы и служебные сведения.

Если программа продолжает сообщать, что сайт ограничил запросы, это **не обязательно ошибка приложения**: ограничение может действовать долго. Повторная попытка передаётся библиотеке, но её ответ не всегда доказывает, что сайт принял отдельный сетевой запрос. Чтобы разобраться, используйте диагностический запуск и сохраните оба журнала.

Технические требования: доступ в интернет и работоспособность неофициального источника данных AliExpress. Программа не пытается обходить CAPTCHA или ограничения сайта и не гарантирует возможность получить точную стоимость заказа из корзины без авторизации.
